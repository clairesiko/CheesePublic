Roquefort

Fromage AOP/ AOC / IGP · AOP, AOC · Occitanie
AOPAOC
  • Espèce : Brebis
  • Type de lait : Lait Cru
  • Type de pâte : Pâte persillée
  • Affinage : 90 jours minimum
  • Saison optimale : Eté, Automne, Hiver
  • Goût : Intense
Le saviez-vous ? L'affinage est obligatoirement réalisé dans les caves situées dans la zone des éboulis de la montagne du Combalou (commune de Roquefort-sur-Soulzon). C'est le premier fromage AOP !
